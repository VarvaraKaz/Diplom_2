# Stellar Burgers API Tests

Автоматизированные тесты API для сервиса **Stellar Burgers**.
Проект реализован в рамках обучения и покрывает основные пользовательские сценарии: регистрация, авторизация и создание заказов.

## Описание проекта

Тесты проверяют корректность работы REST API сервиса:

* создание пользователя
* авторизация пользователя
* создание заказа

Тестирование выполняется с использованием библиотеки `pytest`, HTTP-запросы отправляются через `requests`, а отчёты формируются с помощью `Allure`.

## Используемые технологии

* Python 3.10+
* pytest
* requests
* allure-pytest

## Allure отчёт

### 1. Запуск тестов с генерацией данных

pytest --alluredir=allure-results

### 2. Просмотр отчёта

allure serve allure-results

## Генерация HTML-отчёта

allure generate allure-results -o allure-report --clean
allure open allure-report


## Покрытые сценарии

### Пользователь

* создание уникального пользователя
* создание уже существующего пользователя
* создание без обязательных полей:

  * email
  * password
  * name

### Авторизация

* успешный вход
* вход с неверными данными

### Заказы

* создание заказа с авторизацией
* создание заказа без авторизации
* создание заказа без ингредиентов
* создание заказа с невалидными ингредиентами
